# 우리 버스 · 45인승 수학여행 좌석표

설치·빌드·서버 없이 실행하는 독립 웹앱입니다. 기존 school-trip 앱은 수정하지 않습니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 안의 `index.html`, `style.css`, `core.js`, `app.js`, `.nojekyll`을 저장소 최상위에 업로드합니다. ZIP 자체를 업로드하는 것이 아닙니다. index.html이 저장소 바로 아래에 있어야 합니다.
3. 저장소 Settings → Pages에서 Deploy from a branch를 선택합니다.
4. main 브랜치, /(root)를 지정하고 Save를 누릅니다.
5. 배포 완료 후 표시되는 주소를 기존 수학여행 앱에 링크로 연결합니다.
   예: https://사용자명.github.io/저장소명/

별도 패키지 설치, API 키, 유료 서비스가 필요하지 않습니다. 로컬 확인은 index.html을 브라우저로 여세요. 브라우저에 따라 로컬 파일의 자동 저장이 제한될 수 있으므로 실제 사용에는 GitHub Pages 주소를 권장합니다.

## 사용 방법

- **버스 정보:** 호차·반과 차량 번호판을 입력합니다.
- **사진 촬영 / 사진 선택:** 휴대폰의 카메라 또는 사진 파일을 사용합니다. 사진은 가로·세로 최대 1400px의 JPEG로 변환합니다. 촬영 버튼의 실제 동작은 기기·브라우저 지원에 따릅니다.
- **좌석 제외:** 좌석을 누르면 빨간 X가 표시됩니다. 다시 누르면 해제됩니다. 해당 좌석에 있던 학생 번호는 지워집니다.
- **랜덤 배치:** 시작·끝 번호를 포함한 연속 번호를 중복 없이 배치합니다. 기존 배치 번호는 교체되며 제외 좌석은 유지됩니다. 좌석이 더 많으면 빈자리도 무작위로 정합니다.
- **직접 입력:** 좌석에 번호를 입력한 뒤 다른 곳을 누르거나 Tab으로 이동하면 저장합니다. 중복 번호는 허용하지 않습니다.
- **내 번호:** 학생 번호를 입력하면 좌석을 노란 테두리로 표시하고 위치를 안내합니다.
- **되돌리기:** 최근 좌석 변경·사진 변경·파일 불러오기를 최대 15단계 복구합니다. 새로고침하면 되돌리기 기록은 초기화됩니다.
- **파일 저장 / 불러오기:** 좌석 배치와 버스 이름·번호판·사진이 포함된 JSON 파일을 내려받거나 불러옵니다. 불러오기는 현재 자료를 교체하며, 되돌리기로 취소할 수 있습니다.
- **인쇄 / PDF:** 브라우저 인쇄 창에서 인쇄하거나 PDF로 저장합니다.

## 저장과 공유 범위

현재 버전은 **브라우저별 로컬 저장**입니다. 같은 웹 주소에 접속해도 서로 다른 기기에 자동으로 같은 좌석표가 표시되지는 않습니다. 좌석표를 만든 사람이 파일 저장을 누른 뒤 학생들에게 JSON 파일을 전달하면 학생들은 파일 불러오기로 동일한 좌석표와 사진을 확인할 수 있습니다. PDF로 공유할 수도 있습니다.

사진과 번호판은 서버로 업로드되지 않습니다. 저장 파일을 공유하면 그 안의 사진과 번호판도 함께 전달됩니다. 시크릿 모드 종료·사이트 데이터 삭제 등으로 로컬 자료가 사라질 수 있으니 파일로 보관하세요.

실시간 공동 편집, 교사 로그인, 자동 동기화, 번호판 문자 인식 기능은 포함되어 있지 않습니다. 사진은 눈으로 차량을 확인하는 용도입니다.

## 구조와 추후 연동

- index.html: 화면 및 기존 여행 홈 링크
- style.css: 남색·흰색 테마, 모바일 및 인쇄 스타일
- core.js: 45석 데이터 검증과 랜덤 배치 함수
- app.js: UI, 로컬 저장, 사진, JSON 가져오기·내보내기

좌석 배열은 45개입니다. 인덱스 0~39는 앞에서부터 10줄 × 좌우 2명, 인덱스 40~44는 맨 뒤 5명입니다. 좌석 표시는 1부터 시작합니다. `blocked`는 제외 여부, `number`는 학생 번호 문자열이며 빈 좌석은 빈 문자열입니다. 운전석은 45석에 포함되지 않습니다. 데이터 버전은 1, 저장 키는 `kish-bus-seats-v1`입니다.

기존 앱과의 연결은 해당 앱 메뉴에 이 앱의 배포 주소를 링크로 넣으면 됩니다. 돌아가기 링크는 index.html의 `여행 홈 ↗`에서 변경할 수 있습니다.

## 검증

JavaScript 구문 검사, 100회 랜덤 배치의 중복·제외 좌석 검증, 번호 범위·좌석 수 초과 검사, JSON 왕복 검증을 통과했습니다. 브라우저에서 랜덤 배치, 제외 좌석, 수동 입력, 중복 방지, 새로고침 후 저장 유지 및 390px 화면에서 가로 넘침 없음을 확인했습니다. 실제 휴대폰 카메라 촬영과 프린터 출력은 기기에서 확인해야 합니다.
